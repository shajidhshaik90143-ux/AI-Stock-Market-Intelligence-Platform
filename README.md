# 📈 AI Stock & Market Intelligence Platform

An advanced Python-based financial market research and analytics platform.

## 🚀 Features

- Interactive stock dashboard
- Historical price analysis
- Moving averages
- Watchlist
- Financial news intelligence
- Company fundamentals
- Income statement
- Balance sheet
- Cash flow analysis
- AI market research assistant
- AI news summarization
- ML trend analysis
- Historical anomaly detection
- Historical risk metrics
- PDF research reports
- SQLite database
- Streamlit interface

## 🛠️ Technologies

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Scikit-learn
- yfinance
- Groq API
- SQLite
- ReportLab

## 📂 Architecture

The project separates:

- UI pages
- External data services
- AI services
- ML models
- Database operations
- Utility functions
